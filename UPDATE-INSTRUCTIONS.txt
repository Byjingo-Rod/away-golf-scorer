AWAY GOLF SCORER — VERSION 15.86.6 PLAYER-PHONE STARTUP CORRECTION

This package is the complete Version 15.86.6 app.
It replaces the withdrawn first 15.78 package and includes the Oatlands data
recovery, single-authoritative-course-card protection and My Events visibility
corrections.
This rebuild has a new internal cache identity so the browser cannot reuse the
withdrawn first 15.78 JavaScript file.

1. Close every Away Golf Scorer browser tab and window.
2. Copy every file and folder from this extracted folder into:
   C:\Users\User\away-golf-scorer
3. Choose Replace the files in the destination.
4. Open index.html and confirm that the heading says Version 15.86.6.

No new Supabase SQL is required for Version 15.86.6. If the Version 15.86.4
Spectator SQL was already installed, do not run it again.

VERSION 15.86.6 CHANGES

- Opens a prepared player phone directly at Player Entry after an app restart.
- Prevents the empty My Events window from appearing automatically on that phone.
- Clears the old event code and status message when leaving an event.
