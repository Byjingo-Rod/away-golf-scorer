AWAY GOLF SCORER — VERSION 15.85.4 CONTROLLED TEST UPDATE

This package is the complete Version 15.85.4 controlled-test app.
It replaces the withdrawn first 15.78 package and includes the Oatlands data
recovery, single-authoritative-course-card protection and My Events visibility
corrections.
This rebuild has a new internal cache identity so the browser cannot reuse the
withdrawn first 15.78 JavaScript file.

1. Close every Away Golf Scorer browser tab and window.
2. Copy every file and folder from this extracted folder into:
   C:\Users\User\away-golf-scorer
3. Choose Replace the files in the destination.
4. Open index.html and confirm that the heading says Version 15.85.4.

VERSION 15.85.4 CHANGES
- Stops a reopened published event being appended repeatedly to My Events.
- Consolidates existing duplicate cards only when they identify the same cloud event.
- Preserves the local workspace identity during organiser cloud refreshes.

VERSION 15.85.3 CHANGES
- Clears old phone scores and scoring position when joining a different event.
- Preserves local work when reconnecting to the same cloud event.
- Reloads any genuine scores belonging to the newly joined event from the cloud.

VERSION 15.85.2 CHANGES
- Makes the newest open app tab the sole writer of organiser data.
- Prevents an older open tab with a stale event list from overwriting newer saved events.
- Labels an older tab “Older tab — close this copy” when a newer tab takes control.

VERSION 15.85.1 CHANGES
- Uses a compact two-day event date such as Thu 10 – Fri 11 Sep 2026.
- Reduces the date type slightly so the complete range fits neatly.
- Uses a new cache identity so the browser cannot retain the earlier display.

VERSION 15.85 CHANGES
- Replaces Round / Marker on the Home summary with the event date.
- Adds live blue discrepancy warnings when both cards have arrived but strokes or putts disagree.
- Shows the warning on both affected phones and opens the blue hole directly for correction.
- Keeps red for missing entries and green for complete entries with no known disagreement.
- Prevents a remembered live cloud event from attaching to and replacing an unpublished draft workspace.

VERSION 15.84.1 CHANGES
- Returns a corrected, fully agreeing card to Complete without requiring the player to finalise it again.

VERSION 15.84 CHANGES
- Protects organiser corrections from stale phone uploads.
- Requires current online cards before round or event completion.
- Adds the Unconfirmed Holes correction worklist.

VERSION 15.83.1 CHANGES
- Waiting phones recheck the opening time every five seconds.
- A sleeping phone rechecks immediately when it wakes or returns to the app.

VERSION 15.83 CHANGES
- All scorecards open together 15 minutes before the first tee time.
- The organiser can use Open Scoring Now when an earlier start is required.
- Testing Tools bypasses the timed lock.
- A missing player can still be replaced until that player's group records its first score.
- Rules and Information automatically states the standard scoring-opening rule.

VERSION 15.82.2 CHANGES
- A draft ignores and removes any stale published-event connection carried by an older backup.
- Selecting The Ridge cannot reopen Another 2 Day test.

VERSION 15.82.1 CHANGES
- Selecting a local draft clears the remembered published-event reopening instruction.
- The selected event therefore remains current instead of flashing briefly and being replaced.

Replacing the program files does not erase event plans or scores.

VERSION 15.82 CHANGES
- Select the player who did not arrive before scoring begins.
- The app removes that player, selects a locked virtual player from outside the
  short group and changes the remaining three players to a closed marking loop.
- With two NTP holes, the extra attempts rotate between two different golfers.
- Special Rules explain the arrangement; a compact dropdown below Previous and
  Next Hole shows whether the virtual score for that hole has been verified.
- My Events now switches away from an archived current event reliably.
- The Leaderboard competition strip keeps its horizontal position.

VERSION 15.80 CHANGES
- Two-card checking is required before Complete Round.
- Two-day Stableford leg rows no longer offer separate prizes.
- NTP Jackpot help text spacing corrected.

VERSION 15.79 CHANGES

- Two-day events can use NTP Holes Jackpot.
- Unclaimed earlier NTP ball prizes carry to the final NTP hole.
- NTP results show the actual prize including accumulated jackpot balls.
- The organiser can change a locked single-tee event's Starting Hole before scoring begins.
- Connected phones and every group scorecard receive the new Starting Hole.
- Any score or putt still recorded blocks the change and identifies the player device and hole involved.
