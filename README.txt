AWAY GOLF SCORER — VERSION 10

This rebuild includes:
- Away Golf Scorer branding
- Compact phone-friendly player list using surname and first initial
- Small minus button for permanent player removal
- Editable master player and course databases
- Large course-name display and compact slope/scratch information
- Round-specific manually entered Daily Handicaps
- Separate Day 1 and Day 2 groups
- Random and handicap-balanced group draws
- Independent Par 3 pairs
- Virtual four-ball partner for odd player numbers
- Permanent course-card versions
- Event-only temporary scorecard changes
- Scorecard photo preview and structured 18-line import assistant
- Marker assignments
- Individual self-and-partner score entry
- Hole-by-hole comparison of player and marker records
- Mismatch messages such as “Hole 10: self 5, marker 6”
- Leaderboards based only on verified matching scores
- Optional paper-card and single-group-scorer modes

LIMITATION OF THIS OFFLINE BUILD
Different phones cannot yet exchange scores because the app is not connected to a hosted database. The marker comparison works within this prototype's shared local data. The hosted version will give each player a personal event link and synchronise submissions in real time.
